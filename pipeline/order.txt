hao-runtime-fold-catalog           # B+catalog image only, in hao-runtime-fold's place: the payload built for the B+catalog family (row hao_runtime_fold_catalog, its cache UUID)
darwin27-sandbox-disk-space        # 26A428's system.sb lacks the vfs.disk-space rule (27.2 has it): one Sandbox report per statfs without it

golden-gate-dyld-internal          # dyld alone counts as an internal install (internalInstall() edit), so OCLP's Metal roots load without ic_csr_internal; after hao-runtime (its dyld)

golden-gate-hello                  # first-boot hello and Welcome to Mac: repaired hello shader, un-skip in OCLP's Metal wrapper
golden-gate-windowserver-filter    # two WindowServer rendering paths (Siri bubble filter, backdrop clipping); loads through golden-gate-userspace's display shim
golden-gate-corespotlight-compat   # the CoreSpotlight getter 27's corespotlightd/managedcorespotlightd call on every query
metal-metalold                     # OCLP MetalOld for the 26B131 build (in no current set): before metalold-selectors, which answers its selectors
metalold-selectors                 # Metal selectors OCLP's MetalOld does not answer, via a weak dylib in the HD 4000 Metal driver; built for 26A428, not yet checked on 26B131
golden-gate-metal-framebuffer      # framebuffer reads for RenderBox symbols, a second weak dylib in the same driver; built for 26A428, not yet checked on 26B131
golden-gate-metal-argbuf           # Metal argument buffers + ASTC textures (tools/metal-argbuf): iCBE wrapper and a third weak dylib in the HD 4000 Metal driver; after metal-libraries (its iCBE) and metal-framebuffer; 26B131 only
golden-gate-hd4000-planes          # HD 4000 plane textures (diag#0025 Photos zoom, diag#0024 bands): a fourth weak dylib in the HD 4000 Metal driver gives planes whose pitch differs from plane 0's a shadow texture; after golden-gate-metal-argbuf (previous weak dylib); 25G342 donor (26B131) only
golden-gate-metal-gva              # opt-in (metal-3802-extras), unfolded images only: OCLP's AppleGVA reports Intel hardware JPEG decode unavailable (diag#0025 strip); after the OCLP overlay, before golden-gate-shared-cache (which refuses a changed provider)
metal-compiler-compat              # Live Text 1/3: OCLP's legacy MTLCompilerService loads cache/metallib's compat.dylib (runtime-generated shaders); OS-independent service, row in golden/26B131
golden-gate-live-text-shared       # Live Text 2/3: Vision text recognition runtime in /usr/lib/hao-live-text via libhelloblur; after golden-gate-hello and metal-compiler-compat; 26B131 only (refuses another MPSNDArray library)

golden-gate-native-identities      # Apple originals of the native programs the image re-signed ad hoc + /usr/lib/hao/native-identities, for golden-gate-userspace's code identity carrier. Last oclp-hook: after every recipe that re-signs
opencore-mbp92                     # MacBookPro9,2 early Tahoe display/Ethernet kexts in OpenCore's Kernel.Add (none on recorded builds); split out of hao-opencore, right before it (the model's config first; with no kext to add the config is the same)

golden-gate-font-registry          # fontd registries of this build: Setup's in place, the user seed into PerUserSeed/fonts
