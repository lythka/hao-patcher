golden-gate-windowserver-filter   # two WindowServer rendering paths (Siri bubble filter, backdrop clipping); loads through golden-gate-userspace's display shim
golden-gate-corespotlight-compat  # the CoreSpotlight getter 27's corespotlightd/managedcorespotlightd call on every query
metalold-selectors                # Metal selectors OCLP's MetalOld does not answer, via a weak dylib in the HD 4000 Metal driver; built for 26A428, not yet checked on 26B131

golden-gate-native-identities     # Apple originals of the native programs the image re-signed ad hoc + /usr/lib/hao/native-identities, for golden-gate-userspace's code identity carrier. Last oclp-hook: after every recipe that re-signs
